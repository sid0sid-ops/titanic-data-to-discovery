# Web Predictor Validation Notes

The browser predictor should be validated against the Python export outputs.

## Files

Generated by:

```bash
python3 scripts/export_titanic_web_model.py
```

Outputs:

```text
public/assets/model/titanic_logistic_model.json
public/assets/model/test_predictions.json
```

## Manual Validation Procedure

1. Run the export script.
2. Open `public/assets/model/test_predictions.json`.
3. Start the website:

```bash
npm run dev
```

4. Enter the same passenger values from each `input` object in the predictor form.
5. Compare the website probability with the Python-generated `probability` value.
6. Small rounding differences in displayed percentages are acceptable. Prediction class should match.

## Leakage Check

The exported JSON should only use these input features:

```text
pclass, sex, age, sibsp, parch, fare, embarked, family_size, is_alone, title, has_cabin
```

It must not use:

```text
boat, body
```
