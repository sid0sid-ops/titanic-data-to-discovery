# Website Features

The React website is designed as an interactive explanation of the Colab notebook, not only a landing page.

## Interactive Notebook Timeline

`src/components/NotebookTimeline.jsx` renders the notebook workflow as clickable steps:

- Environment setup
- OpenML data loading
- Raw inspection
- Missing-value cleaning
- EDA
- Feature engineering
- Scikit-Learn pipeline
- Logistic Regression training
- Model evaluation
- Odds ratio interpretation
- Passenger prediction examples
- Final reflection

Each step includes an explanation, why the step matters, a compact code preview, output concept, and key insight.

## Graph Gallery

`src/components/GraphGallery.jsx` displays Python-generated PNG figures from:

```bash
python3 scripts/generate_titanic_figures.py
```

Generated files are saved in:

```text
public/assets/plots/
```

The gallery supports image preview, lightbox viewing, and individual PNG downloads.

## Download Center

`src/components/DownloadCenter.jsx` includes links for:

- Downloading the notebook
- Opening Colab
- Downloading the OpenML dataset
- Downloading the generated graph ZIP
- Viewing the GitHub repository

## Live Passenger Predictor

`src/components/PassengerPredictor.jsx` uses a static JSON model export generated by:

```bash
python3 scripts/export_titanic_web_model.py
```

The website reproduces the Logistic Regression preprocessing and prediction calculation in JavaScript. This is required because GitHub Pages cannot run Python directly.

## Advanced ML Workflow Sections

The website now includes sections for:

- Advanced ML workflow overview
- Model comparison: Logistic Regression vs Random Forest
- GridSearchCV explanation
- React pipeline diagram
- ROC-AUC and ROC curve
- Data leakage warning

The ROC curve is generated from the real model pipeline and saved at:

```text
public/assets/plots/roc_curve.png
```

## Framer Motion Transitions

The site uses Framer Motion for:

- Section reveal animations
- Timeline card transitions
- Hover and tap states
- Graph card lift
- Lightbox open/close transitions
- Predictor result transitions
- Animated probability bar
- Scroll progress indicator

Reduced-motion preferences are respected in interactive components.

## GitHub Pages Deployment

The site is configured for GitHub Pages with:

```js
base: '/titanic-data-to-discovery/'
```

Build command:

```bash
npm run build
```
